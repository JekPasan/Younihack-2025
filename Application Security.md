## Top 10 Vulnerabilities (as of 2021)
1. Broken Access Control
	* bypass security to obtain unintended access within the app or server
	* IDOR --> Insecure Direct Object Reference
2. Cryptographic Failures
	* lack of use (or misuse) of cryptographic algorithms
3. Injections
	* lack of user input sanitization
4. Insecure Design
	* missing or ineffective control design (such as security questions)
5. Security Misconfiguration
	* use of default admin login credentials
6. Vulnerable and Outdated Components
7. Id and Auth Failures
	* brute force attacks
	* use of weak credentials
	* weak session cookies
8. Software and Data Integrity Failures
	* JSON web tokens (change payload username to admin and header encryption to none)
9. Security Logging and Monitoring Failures
	* improper collection, storage, or analysis of app and sys logs
